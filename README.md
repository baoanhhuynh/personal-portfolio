# Clyde Portfolio (React + Vite)

- Swiper hero slideshow (fade, autoplay, nav, pagination)
- Animated counters and reveal-on-scroll (no jQuery)
- Sections: Navbar, Hero, About, Skills, Services, Projects, Testimonials, Blog, Contact, Footer
- Loader hides automatically

## Setup
```bash
npm install
npm run dev
```

## Important (Styles & Images)
For the exact original Colorlib look:
1. Put the **real** template CSS files into `public/css/` (replace the placeholders).
2. Add your images into `public/images/` (`bg_1.jpg`, `bg_2.jpg`, `about-1.jpg`, `work-1.jpg`..`work-8.jpg`, `person_1.jpg`..).
